# Third-party notices

Runtime Python packages retain their own licences. The dependency list is declared in `pyproject.toml`; review and preserve their notices when distributing a container or binary.

Provider integrations are optional clients, not bundled data licences:

- CertStream/Certificate Transparency data is third-party public-log material with source-specific operational and legal conditions.
- URLScan API responses and screenshots remain subject to URLScan's terms. Screenshots are not copied or publicly proxied by default.
- VirusTotal metadata remains subject to VirusTotal's terms and API tier restrictions.

The neutral interface uses system fonts and an original geometric SVG mark, so it does not redistribute the source project's identity or bundled webfont files.
