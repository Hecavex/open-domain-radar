How to read this data

Signals pass through a bounded review pipeline.

Deployments can run from certificate transparency alone. Optional providers enrich existing candidates; a missing key never suppresses a certificate-derived lead.

  1. 01Collect

    Observe certificate names and enabled feeds. Store normalized domains with provenance and timestamps.

  2. 02Match

    Compare against explicit watch targets using explainable lexical and structural rules.

  3. 03Enrich

    Queue optional pivots. Providers without usable credentials are marked skipped, not failed.

  4. 04Review

    Analysts publish, close, or mark false positives. Every disposition remains auditable and reversible.

Confidence is not verdict

The score ranks evidence strength inside this deployment. It does not establish ownership, intent, or harm.

Safe presentation

Potentially dangerous indicators are defanged, rendered as text, and never made directly clickable.

Coverage boundary

Collection is best effort. Absence from the catalogue does not mean a domain is safe or unobserved elsewhere.
